WiFi-Based Indoor Localization

We use WiFi signal strength and machine learning to predict which of four indoor rooms a device is in, without specialized positioning hardware.

Problem statement

Indoor localization is challenging because GPS signals are often weak or unavailable inside buildings. This project investigates whether machine learning can use WiFi Received Signal Strength Indicator (RSSI) measurements to identify a device's room.

Our goal is to classify a device's location as one of four rooms based on signal readings from seven WiFi access points. We compare Decision Tree, Random Forest, and K-Nearest Neighbors (KNN) models using accuracy, precision, recall, and F1-score. KNN achieved the highest test accuracy at 98.50%.

Dataset

The WiFi fingerprinting dataset contains 2,000 observations and eight columns: seven RSSI features, measured in dBm from different access points, and a Location target with four room classes (1–4). Each room has 500 observations, so the classes are balanced.

We checked the data for missing values and verified data types. The WiFi features were standardized, and the data was split using stratified sampling into 1,600 training observations (80%) and 400 test observations (20%).

Approach

  • Loaded and inspected the dataset, checked missing values and data types, and reviewed descriptive statistics.
  • Separated the seven WiFi signal features from the target and standardized the features with StandardScaler.
  • Explored room-label distributions and feature correlations to identify signals useful for distinguishing rooms.
  • Created an 80/20 stratified train-test split to preserve the room distribution.
  • Trained Decision Tree, Random Forest, and KNN classifiers; used GridSearchCV with five-fold cross-validation to tune hyperparameters.
  • Compared test-set accuracy, precision, recall, F1-score, and confusion matrices. KNN reached 98.50% accuracy; Decision Tree and Random Forest each reached 98.00%.

Tools used

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, and Jupyter Notebook.
