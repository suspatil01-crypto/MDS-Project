Air Quality Analysis and AQI Prediction

Exploring air pollution patterns across Indian cities and evaluating machine-learning models for numerical AQI prediction and air-quality category classification.

Problem statement

Air pollution is a significant environmental concern, and its intensity varies across geographical locations and over time. Understanding these variations requires analysing pollutant measurements and their relationship with the Air Quality Index (AQI).

This project investigates historical air-quality observations across Indian cities to identify pollution patterns and evaluate the effectiveness of machine-learning models in predicting AQI values and classifying air quality into predefined categories.

Research objectives

  • Analyse the distribution of AQI values and pollutant measurements across cities.
  • Investigate temporal variations in air quality and relationships between pollutant measurements.
  • Compare regression algorithms for predicting numerical AQI values.
  • Evaluate classification algorithms for predicting AQI categories.
  • Examine model performance using appropriate evaluation metrics and identify influential input features.

Dataset

The project uses the city_day.csv dataset, containing 29,531 daily records across 26 Indian cities and 16 columns. The dataset includes city and date information, pollutant measurements, AQI values, and AQI categories.

The pollutant variables include PM2.5, PM10, NO₂, CO, SO₂, O₃, and other recorded air-quality indicators. These variables provide the basis for exploring pollution patterns and developing predictive models.

AQI values and categories are missing for approximately 15.85% of the records. Missing data must be considered when preparing observations for regression and classification.

Methodology

The analysis follows a structured workflow, beginning with data exploration and preprocessing, followed by exploratory analysis, model development, and performance evaluation.

  • Data preparation: Inspect missing values, duplicate records, data distributions, and city-level coverage.
  • Exploratory data analysis: Examine AQI distributions, compare cities, investigate temporal patterns, and analyse relationships between pollutant measurements.
  • Feature preparation: Prepare relevant input variables and derive calendar features from the date where appropriate.
  • Regression: Train and compare models that predict numerical AQI values.
  • Classification: Train and compare models that predict discrete AQI categories.
  • Evaluation: Use time-ordered data splits and appropriate evaluation metrics to compare model performance.

Prediction tasks

1. AQI regression

The regression task estimates a numerical AQI value from available pollutant measurements and other input features. Models are compared using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and the coefficient of determination (R²).

2. AQI category classification

The classification task predicts the AQI category associated with an observation. Model performance is evaluated using accuracy, precision, recall, and F1-score, providing insight into both overall performance and category-specific errors.

Tools and technologies

  • Python: Data processing and model development.
  • pandas and NumPy: Data manipulation and numerical analysis.
  • Data visualisation: Exploring distributions, trends, and relationships.
  • scikit-learn: Machine-learning pipelines, model training, and evaluation.
