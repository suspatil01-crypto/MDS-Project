THE PROJECT

Problem statement

01 / OVERVIEW
⌁

Can historical pollution data help us understand and predict air quality?

Air quality is influenced by multiple pollutants and varies across locations and time. This project analyses city-wise pollutant measurements and AQI records to identify distributions, relationships, temporal patterns, and differences between cities. It then evaluates machine-learning models for two related tasks: predicting the numerical AQI value (regression) and predicting its AQI category (classification).

Data-quality note

Missing data is substantial for some pollutants: Xylene has 61.32% missing values and PM10 has 37.72%. The notebook uses median imputation for numeric features and most-frequent imputation for categorical features in model pipelines. AQI and AQI_Bucket are each missing in 15.85% of records.
