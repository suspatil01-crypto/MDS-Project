INTERPRETATION

What stands out?

02 / FINDINGS
01

Uneven data completeness

Xylene is missing in 61.32% of rows, PM10 in 37.72%, and NH₃ in 34.97%. Imputation supports modelling but may reduce information quality, especially for sparse features.

02

City-level variation

The notebook's highest city-average AQI values are Ahmedabad (452.12), Delhi (259.49), Patna (240.78), Gurugram (225.12) and Lucknow (217.97). These rankings reflect available records and the dataset period.

03

Particulate matter matters

Gradient Boosting regression assigns the largest feature importance to PM2.5 (0.4898), followed by CO (0.3606) and PM10 (0.0372). Feature importance is model-specific, not causal evidence.

04

Category errors are uneven

In the final Random Forest classification report, recall ranges from 0.35 for Good to 0.90 for Satisfactory. Small supports for Severe (25) and Very Poor (47) make those estimates less stable.

How to read these results

The notebook uses time-ordered splits (70% train, 15% validation, 15% test) for regression and classification. The regression model comparison table is based on validation predictions, while the final Gradient Boosting metrics are reported on the test set. Classification model-comparison scores are validation-stage results; the final Random Forest report is test-set performance. The notebook does not print numerical values for every exploratory graph, so the website only plots figures where values are available in notebook outputs.
