A Comparative and Reproducible Framework for EEG Seizure Detection

Data-Speaks is a reproducible EEG seizure detection framework that compares signal preprocessing techniques and machine learning models using the CHB-MIT Scalp EEG Database. By evaluating seizure detection sensitivity, false alarms, and detection latency, it highlights the importance of reliable, interpretable evaluation in developing safer computer-assisted seizure monitoring systems.

Problem statement

Data-Speaks is a modular framework for EEG seizure detection using the CHB-MIT Scalp EEG Database. Four candidate preprocessing and evaluation approaches were explored, ranging from conventional FIR filtering and independent component analysis (ICA) to artifact-aware processing and patient-level validation. The approaches were compared under common downstream conditions to study the effect of preprocessing while maintaining consistent segmentation, feature extraction, and evaluation. The final architecture emphasizes reproducibility and leakage-resistant validation through explicit patient-level grouping. Seizure detection is evaluated using sensitivity, false detections per 24 h, detection latency, precision-recall area under the curve (PR-AUC), and F1-score. The experiments demonstrate substantial trade-offs between seizure detection, false alarms, and latency, highlighting the importance of evaluating EEG detectors using multiple complementary metrics rather than accuracy alone.

Dataset

The CHB-MIT Scalp EEG Database , a collection of EEG recordings of 22 pediatric subjects with intractable seizures, is now available. Subjects were monitored for up to several days following withdrawal of anti-seizure medication to characterize seizures and assess their candidacy for surgical intervention. In all, the onsets and ends of 182 seizures are annotated.

Approach

  • FIR Filtering + ICA: Standardized EEG channels, applied FIR bandpass filtering (0.5–45 Hz), removed artifacts using Independent Component Analysis (ICA), performed per-channel z-score normalization, and resampled to 256 Hz. Extracted FFT-based spectral features and evaluated machine learning classifiers using Leave-One-Recording-Out validation.
  • Butterworth Filtering + Wavelet Denoising: Applied Butterworth filtering followed by wavelet-based denoising to suppress noise and transient artifacts. Used robust scaling to reduce the influence of extreme signal values, then compared seizure detection performance using the downstream classification and evaluation framework.
  • Butterworth Filtering + ASR + FastICA: Combined Butterworth filtering with Artifact Subspace Reconstruction (ASR) and FastICA for more extensive artifact removal. Standardized the processed EEG signals to 256 Hz and evaluated the resulting representations using machine learning.
  • Modular Cohort Architecture + Patient-Level Validation: Developed a reproducible pipeline with explicit patient grouping and leakage-resistant validation. Standardized EEG channels, applied FIR filtering and ICA, normalized signals, segmented them into two-second epochs, combined three epochs into six-second windows, extracted FFT-based features across eight frequency bands, and evaluated seizure detection using patient-aware validation and event-level metrics.
