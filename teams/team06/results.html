Graphs from the project, with an explanation of what each one shows.

Overall Model Comparision across Patients

This graph compares the overall performance of four machine learning models across the processed patients in our Data-Speaks EEG seizure detection project. It evaluates them using three important metrics: seizure sensitivity, false detections per 24 hours, and detection latency. There is no universally best model across all three metrics. Logistic Regression prioritizes detecting seizures quickly, while KNN offers a better balance in terms of false alarms. The appropriate choice depends on the intended application and the relative cost of missed seizures versus false alerts.

Best Sensitivity By Patient

This graph shows the highest seizure-detection sensitivity achieved for each patient in the Data-Speaks project using the CHB-MIT EEG dataset. The datapoints with no readings denote patients with no actively detected Seizures The graph demonstrates why patient-wise evaluation is important. A model may achieve perfect sensitivity for some patients but perform less effectively for others. Furthermore, perfect sensitivity does not guarantee an effective detector if it generates many false alarms or detects seizures too slowly.

Per Band Energy Shift

Difference in average EEG spectral energy between interictal (outside seizure periods) and ictal (during seizure periods) recordings for one of the Sample Patients (CHB01)

Class imbalance for the Sample Patient (CHB01) dataset

This visualization explains the class imbalance in the CHB01 dataset used in our Data-Speaks EEG seizure detection project. It shows how many EEG windows belong to seizure and non-seizure classes, both overall and across individual recordings.

Top feature importances for seizure -risk regression

This graph shows the top 10 feature importances for seizure-risk regression in patient CHB01 in our Data-Speaks project. It ranks the extracted EEG features according to how much they contribute to the regression model's predictions. Our pipeline transforms cleaned EEG signals into FFT-based spectral features before using machine learning to identify seizure-related patterns. This analysis helps us investigate which features the model finds most useful and may guide future feature selection and model simplification.

PCA of Spectral Features

Visualizes how the EEG windows from seizure and non-seizure periods are distributed in our Data-Speaks project after applying Principal Component Analysis (PCA) to the extracted spectral features.
