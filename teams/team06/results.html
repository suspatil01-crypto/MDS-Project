Overall Model Comparision across Patients

This graph compares the overall performance of four machine learning models across the processed patients in our Data-Speaks EEG seizure detection project. It evaluates them using three important metrics: seizure sensitivity, false detections per 24 hours, and detection latency. There is no universally best model across all three metrics. Logistic Regression prioritizes detecting seizures quickly, while KNN offers a better balance in terms of false alarms. The appropriate choice depends on the intended application and the relative cost of missed seizures versus false alerts.

Best Sensitivity By Patient

This graph shows the highest seizure-detection sensitivity achieved for each patient in the Data-Speaks project using the CHB-MIT EEG dataset. The datapoints with no readings denote patients with no actively detected Seizures The graph demonstrates why patient-wise evaluation is important. A model may achieve perfect sensitivity for some patients but perform less effectively for others. Furthermore, perfect sensitivity does not guarantee an effective detector if it generates many false alarms or detects seizures too slowly.

Top feature importances for seizure -risk regression

This graph shows the top 10 feature importances for seizure-risk regression in patient CHB01 in our Data-Speaks project. It ranks the extracted EEG features according to how much they contribute to the regression model's predictions. Our pipeline transforms cleaned EEG signals into FFT-based spectral features before using machine learning to identify seizure-related patterns. PCA of Spectral Features

Visualizes how the EEG windows from seizure and non-seizure periods are distributed in our Data-Speaks project after applying Principal Component Analysis (PCA) to the extracted spectral features.

Anomalies, observations and patterns

  • Anomaly:
    • ⁠Severe class imbalance: CHB01 contains 36,231 interictal windows but only 112 ictal windows, making seizure detection challenging.
    • Extreme spectral outliers: A few EEG windows exhibit unusually high spectral-feature values, potentially indicating artifacts or atypical signal activity.
    • Several patients have no sensitivity values displayed, potentially because they lack eligible seizure events or evaluated results.
    • ⁠Inconsistent model performance: Logistic Regression achieves high sensitivity but produces substantially more false alarms than KNN and Random Forest.
    • Overlapping feature distributions: PCA reveals that ictal and interictal samples overlap considerably in the first two principal components.
  • Observation:
    • ⁠Higher ictal spectral energy: Seizure windows show substantially higher mean energy than interictal windows across all eight plotted spectral bands.
    • ⁠Important predictive features: Feature 291 has the highest reported importance for CHB01, followed by Features 13, 273, and 149.
    • Patient-specific variability: The best sensitivity differs across patients, with some achieving 100% sensitivity and others showing lower detection rates.
    • Different evaluation outcomes: A model's window-level classification performance does not necessarily translate directly into strong event-level detection.
    • Sensitivity–false alarm trade-off: Logistic Regression prioritizes seizure detection, while KNN produces fewer false detections.
  • Pattern:
    • Seizure-related spectral changes: Ictal and interictal windows exhibit different spectral-energy distributions, providing potentially useful classification features.
    • Majority-class dominance: The large number of interictal windows can bias models toward non-seizure predictions.
    • Uneven feature importance: A small subset of features has higher importance scores than the remaining features.
    • Patient-dependent generalization: Model performance varies across patients, emphasizing the importance of patient-aware evaluation.
    • Complementary evaluation metrics: Sensitivity, false detections per 24 hours, detection latency, PR-AUC, and F1-score reveal different aspects of model performance.
